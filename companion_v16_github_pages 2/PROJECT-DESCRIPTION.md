# 伴你行｜競賽創作說明

AI AGENT CHALLENGE 2026 AI 代理人創作競賽作品

交通服務逐漸數位化，公車到站、捷運轉乘與鐵路購票往往各有不同入口。對較少使用手機交通服務的人來說，查找資訊及理解操作順序可能影響就醫、採買、訪親或社區參與。「伴你行」從當下想完成的交通任務出發，讓使用者選擇直接去官方服務，或依自己的速度跟隨指引。

使用者先選交通工具，再從同一頁直接開啟官方服務或操作指引。圖解用數字與紅框標示官方畫面上的欄位，點一下即可放大。查詢、購票與取票各自有獨立入口。

生成式 AI 參與需求整理、介面與流程設計、官方資料編排、程式撰寫及測試。品牌標誌與運具插畫由使用者提供。朗讀使用裝置的瀏覽器功能。班次、車資、資格、付款與核驗由各官方服務處理。

網站以手機直式、可放大文字、易於點擊的卡片及基本鍵盤操作為設計目標。敬老交通福利分開整理臺北市與新北市的申請條件與使用方式。正式無障礙檢測仍待辦理。
