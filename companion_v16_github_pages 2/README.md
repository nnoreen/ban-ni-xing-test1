# 伴你行 V16

## GitHub Pages 部署
1. 解壓縮 ZIP，將所有檔案及資料夾上傳到 GitHub repository 根目錄。
2. 開啟 Settings → Pages → Build and deployment。
3. Source 選 Deploy from a branch；選 main 與 /(root)，按 Save。
4. 部署完成後，開啟 Pages 提供的網址。

本版由 V16 預覽檔拆分而成，保留原始 JavaScript、CSS 與預覽使用的 WebP 圖片。無需 npm、建置程序或 API Key。問答採本地關鍵字配對；官方查詢需網路，朗讀取決於瀏覽器支援。
